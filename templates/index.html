Palabras Reservadas y Tipos

PalabraTokenFunciónVentajas / Desventajas
intINTDeclaración de variables numéricas enteras.Sintaxis estándar universal / No permite cálculos con precisión decimal.
floatFLOATDeclaración de variables numéricas de punto flotante.Permite cálculos decimales / Errores de precisión flotante.
boolBOOLDeclaración de valores lógicos de verdadero o falso.Ahorra recursos (1 bit) / Limitado a dos estados.
stringSTRING_TYPEDeclaración de cadenas de texto.Facilita almacenamiento de oraciones / Consume más memoria.
voidVOIDIndica la ausencia de un tipo de dato o valor de retorno.Evita exigir retorno / No almacena información.
if / elseIF / ELSEEstructura de control condicional principal y alternativa.Universal y directo / Puede generar código espagueti.
whileWHILECiclo iterativo basado en una condición booleana.Ideal sin conocer iteraciones / Riesgo de bucles infinitos.
forFORCiclo iterativo controlado por un contador.Concentra inicialización en 1 línea / Sintaxis más rígida.
returnRETURNDevuelve un valor procesado y sale de una función.Salidas limpias / Detiene código inferior.
printPRINTImprime datos o mensajes en la consola.Salida rápida de información / No formatea texto nativo.
read_intREAD_INTLee la entrada de teclado como número entero.Evita conversiones manuales / Error si se ingresan letras.
read_floatREAD_FLOATLee la entrada de teclado como número decimal.Ideal para capturar promedios / Vulnerable a formatos no numéricos.
true / falseTRUE / FALSELiterales lógicos de estado.Lectura natural para el programador / No pueden utilizarse para operaciones matemáticas directas.
switchSWITCHEstructura de control de selección múltiple.Simplifica la lectura frente a múltiples bloques if-else / Requiere manejo de casos específicos y suele necesitar break.
